Place the featured `.glb` files for the landmark experience in this folder.

This project now uses the model files that currently exist in the repo, and each file is matched by `modelSrc` in `/features/featured/demo-content.ts`.

Current filenames:

- `babieta.glb`
- `balishengmuyuan.glb`
- `greatwall.glb`
- `hanging gardens.glb`
- `ifeiertieta.glb`
- `jinzita.glb`
- `luomadoushouchang.glb`
- `machu-picchu.glb`
- `maya temple .glb`
- `traditional chinese pagoda 3d model.glb`

Naming guidance for future files:

- Use `.glb`
- Use either pinyin or English
- Prefer lowercase names
- Prefer hyphens instead of spaces when adding new files
- If a filename changes, update the matching `modelSrc` value in `/features/featured/demo-content.ts`
